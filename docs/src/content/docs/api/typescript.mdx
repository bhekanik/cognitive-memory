## CognitiveMemory

Main class for the cognitive memory system.

```typescript
import { CognitiveMemory } from "cognitive-memory";
```

### Constructor

```typescript
new CognitiveMemory(options: {
    adapter: MemoryAdapter;
    embeddingProvider: EmbeddingProvider;
    userId: string;
    config?: Partial<CognitiveMemoryConfig>;
})
```

| Parameter | Type | Required | Description |
|-----------|------|:--------:|-------------|
| `adapter` | `MemoryAdapter` | Yes | Storage backend |
| `embeddingProvider` | `EmbeddingProvider` | Yes | Embedding function |
| `userId` | `string` | Yes | User/agent ID for scoping |
| `config` | `Partial<CognitiveMemoryConfig>` | No | Override defaults |

### Methods

#### `store(input: MemoryInput): Promise<string>`

Store a new memory. Generates embedding, initializes cognitive metadata.

```typescript
const id = await mem.store({
    content: "User is allergic to peanuts",
    category: "semantic",       // default: "semantic"
    importance: 0.9,            // default: config.defaultImportance
    stability: 0.3,             // default: config.defaultStability
    metadata: { source: "chat" }, // optional
});
```

Returns the created memory ID.

#### `search(query: RetrievalQuery, llm?: LLMProvider): Promise<SearchResponse>`

Canonical retrieval API. Combines semantic similarity with retention-weighted scoring, optional deep recall, associative expansion, optional reranking, and retrieval boosting.

```typescript
const response = await mem.search({
    query: "what is the user allergic to?",
    limit: 10,                      // default: 10
    minRetention: 0.2,              // default: config.minRetention
    categories: ["semantic"],        // optional filter
    includeAssociations: true,       // default: true
    deepRecall: false,               // include cold + superseded, exclude stubs
    trace: false,                    // default: false
});
const results = response.results;
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `deepRecall` | `boolean` | `false` | Include cold and superseded records in the candidate set. Stubs stay excluded. |
| `trace` | `boolean` | `false` | When `true`, the response includes a `trace` field with scoring breakdown and pipeline timing details |

Returns a `SearchResponse` object containing a `results` array of `SearchResult` objects sorted by `combinedScore` descending, evidence chains, and an optional `trace` field when tracing is enabled.

Side effects: strengthens retrieved memories (access count, stability, last accessed) and co-retrieval associations.

#### `retrieve(query: RetrievalQuery): Promise<ScoredMemory[]>`

Compatibility wrapper for older callers. It delegates to `search()` and maps each `SearchResult` back to the older `ScoredMemory` shape.

```typescript
const results = await mem.retrieve({
    query: "what is the user allergic to?",
    limit: 5,
});
```

#### `get(id: string): Promise<Memory | null>`

Get a memory by ID. Strengthens the memory on access.

```typescript
const memory = await mem.get("abc-123");
```

#### `queryMemories(filters: MemoryFilters): Promise<Memory[]>`

Query memories with filters. Strengthens returned memories.

```typescript
const memories = await mem.queryMemories({
    categories: ["semantic", "episodic"],
    minRetention: 0.5,
    minImportance: 0.3,
    limit: 20,
});
```

#### `update(id: string, content: string): Promise<void>`

Update a memory's content. Regenerates the embedding.

```typescript
await mem.update("abc-123", "User moved from Portland to Seattle");
```

#### `consolidate(): Promise<ConsolidationResult>`

Run the consolidation process: identify fading memories, compress similar ones, clean up stale data.

```typescript
const result = await mem.consolidate();
console.log(`Decayed: ${result.decayed.length}`);
console.log(`Compressed: ${result.compressed.length} groups`);
console.log(`Promotion candidates: ${result.promotionCandidates.length}`);
console.log(`Converted to stubs: ${result.deleted}`);
```

#### `refreshRetentionScores(): Promise<void>`

Recompute and persist retention scores for all user memories. Useful before consolidation.

```typescript
await mem.refreshRetentionScores();
```

#### `link(sourceId: string, targetId: string, strength?: number): Promise<void>`

Create or strengthen a link between two memories.

```typescript
await mem.link("abc-123", "def-456", 0.7); // default strength: 0.5
```

## Types

### Memory

```typescript
interface Memory {
    id: string;
    userId: string;
    content: string;
    embedding: number[];
    category: MemoryCategory;    // "episodic" | "semantic" | "procedural" | "core"
    importance: number;           // 0.0-1.0
    stability: number;            // 0.0-1.0
    accessCount: number;
    lastAccessed: number;         // timestamp (ms)
    retention: number;            // 0.0-1.0 (cached)
    createdAt: number;            // timestamp (ms)
    updatedAt: number;            // timestamp (ms)
    metadata?: Record<string, unknown>;
}
```

### MemoryInput

```typescript
interface MemoryInput {
    content: string;
    category?: MemoryCategory;    // default: "semantic"
    importance?: number;          // default: config.defaultImportance
    stability?: number;           // default: config.defaultStability
    metadata?: Record<string, unknown>;
}
```

### RetrievalQuery

```typescript
interface RetrievalQuery {
    query: string;
    limit?: number;               // default: 10 for search(), 5 for retrieve()
    minRetention?: number;        // default: config.minRetention
    categories?: MemoryCategory[];
    includeAssociations?: boolean; // default: true
    deepRecall?: boolean;         // default: false
    sessionId?: string;
    trace?: boolean;              // default: false
}
```

### SearchResponse

```typescript
interface SearchResponse {
    results: SearchResult[];
    evidenceChains: string[][];
    trace?: SearchTrace;          // present when trace=true
}

interface SearchResult {
    memory: Memory;
    relevanceScore: number;       // cosine similarity
    retentionScore: number;       // R(m)
    combinedScore: number;        // semantic relevance weighted by retention^alpha
    isAssociative: boolean;
    viaDeepRecall: boolean;        // from a cold or superseded candidate included by deep recall
}

interface SearchTrace {
    stages: StageTrace[];
    totalMs: number;
    totalTokens: number;          // sum of all prompt + completion tokens across stages
}

interface StageTrace {
    name: string;
    candidateCount: number;
    survivorCount: number;
    durationMs: number;
    promptTokens: number;         // LLM prompt tokens used (0 for non-LLM stages)
    completionTokens: number;     // LLM completion tokens used (0 for non-LLM stages)
}
```

When reranking is enabled, the rerank trace stage records the expanded candidate count. For example, `limit: 10` with `rerankFactor: 3` retrieves up to 30 candidates before reranking and returns 10.

### ScoredMemory

```typescript
interface ScoredMemory extends Memory {
    relevanceScore: number;       // cosine similarity
    finalScore: number;           // compatibility alias for combinedScore
}
```

### MemoryLink

```typescript
interface MemoryLink {
    sourceId: string;
    targetId: string;
    strength: number;             // 0.0-1.0
    createdAt: number;
    updatedAt: number;
}
```

### ConsolidationResult

```typescript
interface ConsolidationResult {
    decayed: Array<{ id: string; retention: number }>;
    compressed: Array<{
        summaryId: string;
        originalIds: string[];
        count: number;
    }>;
    promotionCandidates: Array<{
        id: string;
        stability: number;
        accessCount: number;
    }>;
    deleted: number;
}
```

### CognitiveMemoryConfig

```typescript
interface CognitiveMemoryConfig {
    userId: string;
    defaultImportance?: number;   // default: 0.5
    defaultStability?: number;    // default: 0.3
    minRetention?: number;        // default: 0.2
    decayRates?: {
        episodic?: number;        // default: 30 (days)
        semantic?: number;        // default: 90 (days)
        procedural?: number;      // default: Infinity
    };
}
```

### EmbeddingProvider

```typescript
interface EmbeddingProvider {
    embed(text: string): Promise<number[]>;
}
```

### MemoryFilters

```typescript
interface MemoryFilters {
    userId?: string;
    categories?: MemoryCategory[];
    minRetention?: number;
    minImportance?: number;
    createdAfter?: number;        // timestamp
    createdBefore?: number;       // timestamp
    limit?: number;
    offset?: number;
}
```

## Utility functions

```typescript
import {
    calculateRetention,
    updateStability,
    cosineSimilarity,
    scoreImportance,
    categorizeMemoryType,
    extractTopics,
    normalizeVector,
    euclideanDistance,
    BASE_DECAY_RATES,
} from "cognitive-memory";
```

### `calculateRetention(params: DecayParameters): number`

Compute current retention for a memory.

### `updateStability(currentStability: number, daysSinceLastAccess: number): number`

Compute new stability after retrieval (spaced repetition).

### `cosineSimilarity(a: number[], b: number[]): number`

Compute cosine similarity between two vectors.

### `scoreImportance(text: string): number`

Heuristic importance scoring based on text content.

### `categorizeMemoryType(text: string): MemoryCategory`

Heuristic memory category classification.

### `extractTopics(text: string, maxTopics?: number): string[]`

Extract topic keywords from text.
