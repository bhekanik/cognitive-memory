## Read the benchmarks by lifecycle stage

No single memory benchmark proves that a system is "good at memory." Each benchmark rewards a different part of the lifecycle.

LoCoMo is most useful for retrieval coverage, multi-hop associations, and answer utilization over long conversations. LongMemEval-S stresses temporal updates, abstention, and longer human-assistant histories. LTI-Bench is smaller, but it directly probes lifecycle mechanisms such as decay floors, retrieval reinforcement, conflict supersession, and core-memory retention.

That means a high score on one benchmark should not be treated as a universal memory score. The right benchmark depends on the kind of memory your application needs.

## Current interpretation

Cognitive Memory is competitive under the stated protocols, with its strongest evidence on lifecycle behavior and multi-hop recall:

- LoCoMo multi-hop F1 is 48.5%, compared with Mem0 28.4% and FadeMem 29.4% under the cited comparison protocol.
- LongMemEval-S is 70.2%, competitive with ENGRAM-class single-stage memory systems but not a current leaderboard claim.
- LTI-Bench retains 100% of identity-critical facts in the controlled 30-day harness.
