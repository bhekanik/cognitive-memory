## What this comparison says

Under the cited LoCoMo comparison protocol, Cognitive Memory scores higher on overall and multi-hop token F1. The largest gap is multi-hop, which is the setting most directly helped by associative expansion and broader recall.

This is not a claim that Cognitive Memory is better than Mem0 for every workload. Mem0 is a strong, simpler memory layer, and its hosted/product implementation may differ from any specific benchmark harness.

## Architectural difference

The main difference is lifecycle dynamics. Cognitive Memory explicitly models:

- decay-weighted ranking with `sim(m,q) * R(m)^alpha`
- retrieval reinforcement
- association links between memories
- cold/superseded records for deep recall
- queued conflict handling and consolidation

That extra machinery has cost and complexity. It is most useful when memory accumulates across many sessions and old, updated, or associated facts still matter.

## Fair comparison notes

- Use this page as a protocol-specific comparison, not a universal leaderboard.
- Mem0 results are treated as published/cited baseline numbers.
- Cognitive Memory results are current logged paper numbers.
- Benchmark scores should be matched to the memory behavior your product needs.
