## About LoCoMo

LoCoMo (Long Conversation Memory) tests long-term conversational memory across multiple question types:

- **Single-hop:** direct recall of a single fact
- **Multi-hop:** combining two or more facts
- **Temporal:** questions about when events happened
- **Open-ended:** questions with looser answer boundaries

The standard result here uses 10 conversations and the 1,540 category 1-4 questions reported in the paper/logs.

## What changed from older runs

Older run labels such as Run F and Run H are historical. The active LoCoMo number is the current SDK full run, not the earlier conv-0 rerank pilot.

The old conv-0 rerank pilot remains useful as an ablation signal, but it should not be cited as a full benchmark result.

## What we learned

### Multi-hop is the strongest LoCoMo signal

The 48.5% multi-hop F1 result is the clearest LoCoMo evidence for associative retrieval and broader candidate recall. Multi-hop questions often require a memory that is related to another retrieved memory, not directly similar to the query.

### Retrieval is still the bottleneck

The oracle evidence ceiling is much higher than the current end-to-end score. That means the architecture helps, but better retrieval and answer use are still major improvement areas.

### Temporal questions remain difficult

Temporal questions require precise date extraction and as-of reasoning. They remain harder than ordinary factual recall and are called out as future work in the paper.

## Methodology

All current LoCoMo results use:

- 10 conversations
- 1,540 category 1-4 QA items
- `gpt-4o-mini` for extraction and answering
- `text-embedding-3-small` embeddings
- GPT-4o judge
- current SDK scoring: `sim(m,q) * R(m)^alpha`, default `alpha=0.3`

See [Methodology](/cognitive-memory/benchmarks/methodology/) for the pipeline and [experimentlog.md](https://github.com/planetaryescape/cognitive-memory/blob/main/cognitive-memory-benchmarks/experimentlog.md) for logged artifacts.
